#    b) Migration Runner: Runs Diesel migrations in Kubernetes Job

#    a) Library: Imported by DataEngine for Redis connection pooling

# 3. DataEngine - THE MAIN APPLICATION:
#    a) Uses databaseschema library for DB connections
#    b) Uses redisutils library for Redis connections
#    c) Runs as the main service

# redisutils doesn't need a Docker image (it's just a library)
